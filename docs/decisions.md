# Design decisions

- 2026-10-31: `Bridge::on_tx_done` returns `Option<BusEvent>` so internal allocation polls do not fabricate host/local TX events; the chosen address emits `LaAllocated`, and the physical-address announcement links to it.
- 2026-10-31 (D1/M3): A directed transmission ending after a NACKed block is complete once high past `DATA_TOTAL.max` from the ACK fall, even without EOM. Publish the received blocks as `Frame { ack: false }`, not a timing error, preserving absence evidence.
- 2026-10-31 (D2/M1/M2): Silently drop idle data-width pulses; suppress repeat errors until a valid start pulse. Keep edge-order timestamps independent of `poll`. Executor order is read now, drain GPIO edges, poll, then TX completion, preventing false out-of-order errors and late echoes.
- 2026-10-31 (D3/M4): Add `Decoder::set_transmitting(bool)`; never ACK our own sends and never synthesize sampled ACK from membership. Rebuild allocation ACK membership from the selected LA plus configured extras, excluding the candidate while polling. The fixed LA (first type candidate for auto) is the implicit own entry, not an extra, removing the stale default `[0]`.
- 2026-10-31 (D4/M5): Add one-shot `TxAction::Abort` after mid-block arbitration/line failure so the executor cancels RMT and releases the line immediately.
- 2026-10-31 (D5/M6/m9): RMT is TX-only; receive edges and follower ACK triggers require a timestamping GPIO ISR. `SendBlock` includes ACK trailing high; queue the next block immediately after positive ACK, with explicit `block_start_us` equal to the previous end so relative samples stay correct for queued transactions. `AckDue::fall_at_us` is only a prediction; actual fall triggers ACK.
- 2026-10-31 (D6/M7/m5): Replace `Tx::step(now, bus_busy)` with `step(now, quiet_since_us)` and expose `Decoder::quiet_since_us(now)`. Busy/low returns now; otherwise use last edge, extended to ACK fall + BIT at frame completion. Recheck every step; foreign activity uses NEW instead of SAME/RETRY; bookkeeping retains only the two-second give-up clock.
- 2026-10-31 (D7/M8): Public `Bridge::next_seq()` allocates from the one wrapping per-boot counter for rejected/busy, line, and overrun events emitted by the executor.
- 2026-10-31 (D8/M9, revised with lead approval): Lenient `RawTxRequest` owns bounded `String<32>` id and `String<64>` data, with u64 numeric fields; borrowed strings cannot support escaped JSON without allocation. Validation returns `Submission` or `(Option<RequestId>, Reason)`. Ingress overflow, wrong types and malformed JSON become uncorrelated `malformed` rejection. Omit unavailable ids (not null); rejected destination/data are optional when invalid/overlong. Remove impossible bounded-length `SubmitError` variants; retain destination validation because `Frame` fields are public. Retries clamp to MAX_ATTEMPTS - 1.
- 2026-10-31 (D9/M10): Separate frame-level `RxError::LineLow` (`err kind:line_low`) from stateful bus health at `timing::STUCK_LOW = 100_000`. Add `RxEvent::Line` and `BusEvent::Line` with stuck/recovery transitions; proto maps to `line bus:stuck_low|ok`.
- 2026-10-31 (D10/m1/m2): Count NACKs independently from arbitration/line failures; retry while nacks <= retries and attempts < MAX_ATTEMPTS. Final attempt wins for status, correcting contradictory all-attempt wording.
- 2026-10-31 (D11/m3): Samples over `timing::SAMPLE_SLACK = 200` µs late are line errors, including never-delivered samples, avoiding infinite past-deadline waits.
- 2026-10-31 (D12/m4/m10): `TxAction::Done { outcome, final_attempt_start_us }` authoritatively timestamps `Bridge::on_tx_done(outcome, start_us)`. Remove the decoder-echo timestamp override; match echoes only to suppress local replies. Wait final ACK completion (past decoder timeout for NACK) and drain RX before TX publication.
- 2026-10-31 (D13/m6/m7/m8, Luna 1/2): String visitors accept escaped JSON; manual bus decoding bounds addresses to 15; unknown kind/status values remain errors, while unknown keys are ignored. `serde_json` is optional under std and a dev-dependency. Name `OtaRequest` and `StateRequest` in the API contract (rename the former `StateCommand`).
- 2026-10-31 (Luna 3/4): Acceptance explicitly covers ACK sampling at SAMPLE_AT and line-error retries with retries=0. ACK pulse timing accepts the combined low range because initiator/follower share the line; its sampled polarity, including a rise exactly at SAMPLE_AT, is independent of ack-set membership.
